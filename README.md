🚀 Sriram | AI & Software Portfolio

A modern, animated personal portfolio built with pure HTML, CSS and JavaScript. No frameworks, no build step, just one file.

🔗 Live site: https://sriramverse30-a11y.github.io/sriram-portfolio/

✨ Features
Letter-by-letter animated hero with a typewriter role changer
Interactive particle network that reacts to the mouse
Custom trailing cursor, magnetic buttons and click sparkles
3D tilt and spotlight effects on cards
Animated skill bars and a live code-typing panel
Scroll progress bar and a floating navigation bar
Settings panel: light/dark theme, particles, sparkles, calm motion and accent colours (saved in the browser)
Fully responsive and respects reduced-motion preferences
🛠️ Tech Stack
HTML5
CSS3 (animations, glassmorphism, CSS variables)
Vanilla JavaScript (Canvas API, Intersection Observer)
